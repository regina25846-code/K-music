선택 — YouTube API 키 설정(조회수 가산점용)

🔒 이 키는 선택 입력입니다.
추천곡 중 조회수가 높은 곡에 가산점을 주는 기능에만 쓰이고, 키를 안 넣어도 K-Music의 다른 모든 기능은 그대로 작동합니다. 하루 무료 할당량이 1만 회라 개인 사용으로는 거의 소진될 일이 없습니다. 입력한 키는 내 컴퓨터에만 저장되고 외부로 전송되지 않습니다.

STEP 1
Google Cloud Console 접속
console.cloud.google.com에 접속 후 Google 계정으로 로그인합니다.
처음 접속하면 서비스 약관 동의 화면이 나옵니다. 국가를 선택하고 약관에 동의 후 계속하면 됩니다.
STEP 2
새 프로젝트 만들기
상단 프로젝트 선택 → 새 프로젝트 클릭. 이름은 자유롭게 지정하세요.
이미 K-Tube 등 다른 K-앱용으로 만들어둔 프로젝트/키가 있다면 그대로 재사용해도 되지만, 할당량을 나눠 쓰게 되니 여유가 있다면 K-Music 전용 프로젝트를 새로 만드는 걸 권장합니다.
STEP 3
YouTube Data API v3 사용 설정
왼쪽 메뉴 → API 및 서비스 → 라이브러리 → YouTube Data API v3 검색 → 사용 설정.
STEP 4
API 키 발급
API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키 클릭 후, 생성된 키를 복사해두세요.
STEP 5
K-Music에 키 입력
앱 실행 후 설정 → 내 계정 → 유튜브 API 키 칸에 붙여넣으면 완료됩니다.
