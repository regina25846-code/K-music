05

YouTube API 키 설정

선택 사항

K-Music은 내 재생 기록을 학습해서 다음 곡을 고릅니다. 여기에 “조회수 가산점”을 얹으면 비슷한 후보들 사이에서 더 많이 들린 곡이 살짝 앞으로 나옵니다. 이 가산점을 켜려면 YouTube Data API 키가 필요한데, 넣지 않아도 추천 자체는 그대로 작동합니다 — 이 가산점만 꺼진 채 취향 기반 순서가 유지됩니다.

같은 연대끼리만 비교합니다

추천 후보를 발매 연대(예: 2020년대끼리, 1990년대끼리)로 묶고, 그 그룹 안에서만 조회수를 상대 비교합니다. 오래된 곡이 조회수 총량에서 무조건 불리해지는 걸 막기 위해서로, 다른 시대 곡끼리는 아예 비교하지 않습니다.

로그 스케일로 최대 +3점

조회수는 로그 스케일로 정규화한 뒤, 그룹 안 최댓값 대비 비율만큼 최대 +3점까지만 더합니다. 조회수는 자릿수 차이가 크게 벌어져도 체감 인기 차이는 훨씬 완만하다고 보기 때문입니다.

어디까지나 보조 신호입니다

내 취향 기반 점수(가수·채널·즐겨찾기 등, 최대 ±6~8점대)가 훨씬 크게 작동합니다. 조회수 가산점은 그 신호를 밀어내지 않는 선에서 순위를 살짝 조정하는 역할만 합니다.

키는 내 컴퓨터에만 저장됩니다

하루 무료 쿼터가 1만 회라 개인 사용으로는 거의 소진되지 않습니다. 입력한 키는 내 컴퓨터에만 저장되고 외부로 전송되지 않습니다.

이 키는 선택 입력입니다. 넣지 않으면 조회수 가산점만 꺼지고, K-Music의 다른 모든 기능(재생·검색·플레이리스트·추천)은 그대로 작동합니다.

STEP 1

Google Cloud Console 접속

console.cloud.google.com에 접속해 Google 계정으로 로그인합니다. 처음 접속하면 서비스 약관 동의 화면이 나오는데, 국가를 선택하고 약관에 동의한 뒤 계속하면 됩니다.

STEP 2

새 프로젝트 만들기

상단 프로젝트 선택 → 새 프로젝트 클릭. 이름은 자유롭게 지정하세요. 이미 K-Tube 등 다른 K-앱용으로 만들어둔 프로젝트·키가 있다면 재사용해도 되지만 할당량을 나눠 쓰게 되니, 여유가 있다면 K-Music 전용 프로젝트를 새로 만드는 걸 권장합니다.

STEP 3

YouTube Data API v3 사용 설정

왼쪽 메뉴 → API 및 서비스 → 라이브러리 → YouTube Data API v3 검색 → 사용 설정.

STEP 4

API 키 발급

API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키 클릭 후, 생성된 키를 복사해 둡니다.

STEP 5

K-Music에 키 입력

앱 실행 후 설정 → 내 계정 → 유튜브 API 키 칸에 붙여넣으면 완료됩니다.
