⬇ 설치형 다운로드 ⬇ 포터블 다운로드

설치 안내

  1. 설치형 다운로드 클릭 후 exe 실행
  2. Windows 보안 경고 시 "추가 정보" → "그래도 실행"
  3. 설치 완료 후 K-Music 실행

주요 기능

🎵 유튜브 스트리밍다운로드 없이 바로 재생 (yt-dlp)
🔍 유튜브 검색검색 결과에서 바로 추가
📋 플레이리스트여러 개 만들어 관리
🎚 음질 설정128k / 192k / 320k 선택
🔀 셔플·반복전체·한곡 반복, 셔플 모드
🖥 트레이 백그라운드창 닫아도 계속 재생
📌 항상 위 고정다른 창 위에 표시
🔄 자동 업데이트새 버전 자동 감지
